URLs

Read this for: the path, the URL name, and who is allowed to open it.

Source files: config/urls.py, apps/accounts/urls.py, apps/diary/urls.py, apps/accounts/views.py, apps/diary/views.py

config/urls.py mounts admin at /admin/, accounts at /accounts/, and diary at /. Account URL names are global, not namespaced, because Django's password-reset views reverse password_reset_done and the other stock names.

A new view is private. LoginRequiredMiddleware redirects a signed-out request to sign-in unless the view is marked login_not_required. Add a row to tests/test_authorization.py in the same change. That test fails when a product URL name is missing from its table. It requests each row as a normal page and with HX-Request.

PathNameWho
/homeSigned in. Redirects to today's day page in that person's time zone
/d/<YYYY-MM-DD>/daySigned in. That day's entries they can read. Diary view unless ?view=raw. ?diary=<id> limits the day, the marks, and the day list to one readable diary. An invalid date, view, month, or diary id is 404
/entries/new/entry_createSigned in. A new entry. Blank text, no diary, or an invalid date saves nothing. A diary they cannot read returns 404
POST /entries/autosave/entry_autosave_createSigned in. Creates one entry when the text is not blank, and returns the new revision. A repeated write number for the same editor returns the entry already stored. Blank text saves nothing. GET returns 405
/entries/<id>/entryA member of one of its diaries. The current owner can edit. Another member gets 403 on save. Anyone else gets 404
POST /entries/<id>/autosave/entry_autosaveThe entry's current owner. Same revision rule as the edit form. A member who cannot edit gets 403. Anyone else gets 404. GET returns 405
POST /entries/<id>/delete/entry_deleteThe current owner removes the entry from every diary. An Owner or Editor of one of its diaries removes it from the posted diary, and deletes the entry when that was its only diary. A member who cannot delete gets 403. A diary they cannot read is 404. Anyone else gets 404. GET returns 405
POST /entries/<id>/transfer/entry_transferThe current owner. Another member gets 403. Anyone else gets 404. An empty email or a transfer to yourself changes nothing. GET returns 405
POST /entries/<id>/transfers/<id>/cancel/entry_transfer_cancelThe current owner, for a pending transfer of that entry. Another member gets 403. Anyone else gets 404. GET returns 405
/entry-transfers/<token>/entry_transfer_pageAnyone with a pending token. A used or unknown token is 404. Signed in as a different account, the page does not show the entry. Signed out, the page does not show the entry text
POST /entry-transfers/<token>/accept/entry_transfer_acceptThe account with that email, signed in. The wrong account gets 404. Signed out, redirects to sign-in. GET returns 405
POST /entry-transfers/<token>/decline/entry_transfer_declineThe token holder. A different signed-in account gets 404. GET returns 405
/diaries/diariesSigned in. That person's diaries, defaults, and the create form
POST /diaries/new/diary_createSigned in. Creates a diary they own. It is private unless Shared diary is checked. GET returns 405
POST /diaries/<id>/rename/diary_renameThe Owner. Another member gets 403. Anyone else gets 404. A blank name changes nothing. GET returns 405
POST /diaries/defaults/diary_defaultsSigned in. Sets that person's defaults. An id they cannot read gets 404 and changes nothing. GET returns 405
/diaries/<id>/members/diary_membersA member. Lists members. A shared diary also shows invite and pending invitations to someone who may send them, role changes to the Owner, removal to whoever the role table allows, and Leave to anyone except the Owner. The Owner also sees ownership transfer. Anyone else gets 404
POST /diaries/<id>/members/<user_id>/role/member_roleThe Owner, setting another member to Editor or Contributor. The Owner's own role is 403. Another member gets 403. Anyone else gets 404. The same role changes nothing. GET returns 405
POST /diaries/<id>/members/<user_id>/remove/member_removeThe Owner, for an Editor or a Contributor, or an Editor, for a Contributor. The Owner cannot be removed. Removing yourself is 403. Another member gets 403. Anyone else gets 404. GET returns 405
POST /diaries/<id>/leave/diary_leaveAn Editor or a Contributor. The Owner gets 403 until an accepted transfer makes them an Editor. Anyone else gets 404. GET returns 405
POST /diaries/<id>/transfer/diary_transferThe Owner. Another member gets 403. Anyone else gets 404. An empty form, or a transfer to yourself, changes nothing. GET returns 405
POST /diaries/<id>/transfers/<id>/cancel/ownership_cancelThe Owner, for a pending transfer of that diary. Another member gets 403. Anyone else gets 404. GET returns 405
/transfers/<token>/ownership_transferAnyone with a pending token. A used or unknown token is 404. Signed in as a different account, the page does not name the diary
POST /transfers/<token>/accept/ownership_acceptThe account with that email, signed in. The wrong account gets 404. Signed out, redirects to sign-in. The link does not create an account. GET returns 405
POST /transfers/<token>/decline/ownership_declineThe token holder. A different signed-in account gets 404. GET returns 405
POST /diaries/<id>/invitations/diary_inviteAn Owner, for an Editor or Contributor invitation, or an Editor, for a Contributor invitation, on a shared diary. Another member gets 403. A private diary is 403 for its owner. Anyone else gets 404. GET returns 405
POST /diaries/<id>/invitations/<id>/revoke/invitation_revokeThe same roles as invite, for a pending invitation of a role they may offer. Another member gets 403. Anyone else gets 404. GET returns 405
/invitations/<token>/invitationAnyone with a pending, unexpired token. A used, revoked, expired, or unknown token is 404. Signed-in as a different account, the page does not name the diary
POST /invitations/<token>/accept/invitation_acceptThe invited email. An existing account must be signed in as that email. An unknown email creates the account. The wrong account changes nothing. GET returns 405
POST /invitations/<token>/decline/invitation_declineAnyone holding a pending, unexpired token. GET returns 405
/accounts/login/loginAnyone. A signed-in person is sent home
POST /accounts/logout/logoutAnyone. Ends the session and returns to sign-in. GET returns 405
/accounts/password-reset/password_resetAnyone
/accounts/password-reset/done/password_reset_doneAnyone
/accounts/reset/<uidb64>/<token>/password_reset_confirmAnyone. An expired or used link renders the invalid-link page
/accounts/reset/done/password_reset_completeAnyone
/accounts/register/registerAnyone, and 404 unless registration is open
/accounts/settings/settingsSigned in. Edits that person only. Also shows Delete account
POST /accounts/delete/account_deleteSigned in. Closes that person's account after the current password. A wrong password, or a shared diary that still needs a successor, changes nothing. GET returns 405
/accounts/privacy/privacyAnyone. Who can read an entry, what the service can read, and how deletion works. It stores nothing
/admin/adminStaff. Users, site settings, the reinstate action, and read-only diaries and memberships. A diary in custody has its own screen for retain, reassign, and delete. It does not list entries. A signed-out request goes to the admin sign-in page. A signed-in non-staff person is sent there too
Unknown pathAnyone. The 404 template. Not a redirect to sign-in
Server errorAnyone. 500.html

How sign-in, the session, and the reset link behave is on Authentication. What the role checks allow is on Permissions. How a save and a stale edit behave is on Entries and autosave.
