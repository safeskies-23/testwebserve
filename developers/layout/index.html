Where a file goes​

  • config/ holds settings, root URLs, ASGI, WSGI, the theme context processor, and the client-IP callable. It holds no feature models.
  • Django apps live in apps/<label>/ and are imported as apps.<label>. The label is the directory name. accounts and diary stay fixed. accounts already has a migration.
  • A feature goes in the app that already owns its domain. Add an app only for a separate domain with its own models, screens, and rules, and say why. Being new is not a reason.
  • Everything a feature owns stays in that app: models, views, forms, services, permissions, management commands, admin, templates, static files, and tests.
  • Services are plain modules in apps/<app>/services/. Views call them. Do not wrap services in another layer. accounts sends mail from apps/accounts/services/mail.py. Diary writes go through apps/diary/services/diaries.py. Entry writes go through apps/diary/services/entries.py.
  • App templates live in apps/<app>/templates/<app>/. The day page is diary/day.html. Its swapped region is diary/browse.html, which includes diary/month.html, diary/raw.html, and diary/diary_view.html. The Diaries page is diary/diaries.html. The write and edit page is diary/entry_form.html.
  • App static files live in apps/<app>/static/<app>/. The editor script is apps/diary/static/diary/autosave.js.
  • App tests live in apps/<app>/tests.py or an apps/<app>/tests/ package. Account tests are apps/accounts/tests.py. Diary tests are apps/diary/tests.py.
  • Root templates/ is shared chrome only: base.html, 403.html, 404.html, 500.html, partials/fields.html, and templates/registration/ for sign-in, password reset, registration, and the lockout page. Settings is apps/accounts/templates/accounts/settings.html.
  • Root static/ is site-wide: css/app.css, css/themes.json, js/theme.js, js/htmx.min.js, and fonts/source-sans-3/.
  • Root tests/ is for checks that span apps. Run them with python manage.py test tests.
  • Root docs/ is the canonical Markdown. docs/index.md introduces the product. User help is docs/help/. An investigation starts at docs/developers/index.md. docs/planning/ is intent and is excluded from the docs site. The README stays a short map.
  • The Pebble Diary docs site is /Users/safeskies/Programming/Utilities/Docusaurus/sites/pebble-diary/. sites/pebble-diary/sidebars.ts lists the pages the site shows. sites/pebble-diary/docusaurus.config.ts reads this repo's docs/.
  • AGENT_CONTEXT.md stays at the repository root. It is not a docs page and it is not on the site.
  • .cursor/rules/ holds the short rules that point here.

TEMPLATES["DIRS"] finds the root templates. APP_DIRS finds app templates.

Do not squash or regenerate a migration that has been applied anywhere. apps/accounts/migrations/0001_initial.py creates User and SiteSettings. apps/diary/migrations/0001_initial.py creates Diary and DiaryMembership, then backfills a personal diary for each existing account. apps/diary/migrations/0002_entry.py creates Entry and EntryMembership. apps/diary/migrations/0003_autosave_write.py adds the autosave editor id and write number.

Which module implements a behavior is on the page for that behavior. The task router is Developers.
